# VERALIQ Enterprise Light — asset manifest

All files below were hand-authored for this delivery (plain SVG markup or a
local headless-Chrome screenshot of the real, unmodified site). Nothing was
downloaded from a stock library or generated by an external image model, so
there is no third-party license to track — copyright rests with the project
owner the same as the rest of the repository. No real customer names, phone
numbers, emails, deed/title data or financial figures appear in any asset.

**Not delivered / blocked**: authenticated admin and portal dashboard interiors
(stat cards, tables, lead/portfolio/appointment views). This sandbox has no
Cloudflare D1/worker credentials, so those views cannot be logged into and
render as an empty shell locally — see `06-SOURCE-CONTEXT.md`'s own caveat
about this limitation. The CSS rules that will style them
(`.card`, `.stat-card`, `table`/`th`/`td`, `.pill`, `.sidebar`, `.topbar`) were
verified by grep-matching every selector name against admin.html/portal.html's
real inline `<style>` and JS template strings — see the "Apply VERALIQ
Enterprise Light..." commit message for the exact validation method — but
were not visually confirmed against live, populated data.
